# Young-Methy-Comparation

浏览器内运行的 Sanger/AB1 甲基化比较工具。可直接上传已有 CSV/Excel 表格，也可用原版 **Young-methy-Analysis-Tool** 的 AB1 比对、片段合并和 CpG 表格生成算法得到可比较的数据。上传文件只在当前浏览器会话的临时内存中读取，不发送到应用服务器，不使用本地持久存储；刷新页面会清空数据。浏览器生成下载文件时，设备仍会短暂使用内存和用户选择的下载位置。

在线地址：<https://youngxxx123.github.io/Young-Methy-Comparation/>

## 使用方法

1. 选择多个 CSV、TSV、XLS 或 XLSX。表格需有 `Distance_to_Target_Center`（或其他含 `Distance` 的列）以及 `Average_C_Ratio` / `Average_C` 列；甲基化比例可写为 0–1、0–100 或带 `%` 的值。每个文件或工作表视为一个独立批次，在「输入数据与独立批次」中修改其条件组和批次名称。
2. 若要从 AB1 直接生成表格，输入参考 DNA 序列及在其中**恰好出现一次**的靶序列，先填写本次上传所属的条件组和独立批次，再选择多个 AB1，点击「比对 AB1 并生成 CpG 表格」。同次选择的读段自动归入所填组与批次，也可在读段列表逐条修改；上传另一独立批次前先改批次名。同组同批次的多段及双向 AB1 按参考坐标合并，重叠位点取 Phred 较高的读数，最终**每个独立批次一张表**。生成的表格自动进入比较，也可单独下载 CSV。当前流程按 CT 转化分析。
3. 在比较规则中选择条件组。若组名同时含 `DNMT3a` 与 `DNMT1`，默认比较这两组；可以手动增减。每组至少有 3 个**独立、不配对的批次**时，逐 CpG 使用 Welch 单因素 ANOVA（也可选择普通单因素 ANOVA），可按 P<0.05 或 BH 校正 Q<0.05 标注。若任何所选组不足 3 批，则不做显著性检验，只把组间平均甲基化比例差**严格大于** 20 个百分点的位点标为红色小星号。批次内多个 AB1 是技术片段，不增加独立重复数。
4. 所有条件组在同一列、共用横坐标。拖动图谱选择范围、点击图谱后按 `+` / `-` 缩放、双击回到全长；最窄为 50 bp。也可输入起止坐标，保存多个区域。`R01`、`R02` 等仅为保存区域的编号。选定区域后，在右侧「为此区域补充 AB1 峰图」中填写**区域共用**的参考 DNA 与靶序列，选择本次上传的样本和批次，再上传多条 AB1。多个区域共用参考输入，但各自保存上传文件及展示选项；此入口不会生成或改变比较表格。同一样本、同一批次的读段按原工具的参考序列比对和逐位点最高 Phred 质量逻辑拼接，峰图展示被选中读段的真实荧光信号；没有读数的位置留白，不设置区域覆盖率门槛。不同批次分开展示。可开启最低 Phred Q 过滤，或打开 Focus，仅保留每个有读数的 CpG C 位点及左右各 2 bp，并以该位点为中心原位等比例放大 1.35 倍，与区域放大图保持横坐标对齐。
5. 可预览合并报告，下载合并 PNG/PDF，也可分别下载甲基化主图 PNG、AB1 峰图 PNG。报告中的小红星与当前比较规则一致，区域峰图遵循各区域当前的质控和 Focus 选择。所有导出由浏览器完成。

缺失的 CpG 比例不会被当作 0；逐位点检验要求每个参与组在该位点都有至少 3 个有效独立批次。ANOVA 标记表示**所选组的总体检验**，不表示任意特定两组的事后比较。比例数据的 ANOVA 也需要考虑独立性、分布和方差条件；重复数较少时应结合实验设计解释。

## 本地运行与发布

需要 Node.js 22.12 或更新版本。

```bash
npm ci
npm run dev
```

打开终端显示的本地网址（路径包含 `/Young-Methy-Comparation/`）。运行 `npm test` 会执行算法测试与生产构建。推送到本仓库的 `main` 后，GitHub Actions 工作流运行测试并将 `dist` 发布到 GitHub Pages；仓库 Settings → Pages 的 Source 应设为 **GitHub Actions**。

`src/legacy-alignment.ts` 复制自项目作者现有的 [Young-methy-Analysis-Tool](https://github.com/YoungXXX123/Young-methy-Analysis-Tool)，保留其 AB1 比对、质量修剪、片段合并和 CpG 表格算法。新工具没有修改原仓库。唯一新增的导出语句供区域峰图复用相同的局部比对核心。
